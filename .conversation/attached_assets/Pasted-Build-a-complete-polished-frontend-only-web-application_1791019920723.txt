Build a complete, polished frontend-only web application called **AccessShield X**.

Do NOT build a backend, database, API, authentication server, Kafka, Redis, or FastAPI.

Use realistic local mock data and frontend state so the entire website is fully interactive and demonstrable.

## BRAND

Name:
**AccessShield X**

Subtitle:
**Intelligent IAM Least-Privilege Auditor**

Tagline:
**Detect. Explain. Minimize. Secure.**

The product analyzes cloud access logs against IAM policies and identifies unused, excessive, and overbroad permissions, then displays least-privilege recommendations.
